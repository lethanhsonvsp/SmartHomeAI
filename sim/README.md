# Mô phỏng phần cứng

Chưa có ESP32, Tapo C222, P100. Thư mục này chứa bộ mô phỏng để phát triển trước:
- ESP32: publish SHT30, BH1750, MC-38 lên MQTT, nhận lệnh buzzer.
- P100: adapter LAN giả, ghi trạng thái bật/tắt.
- Camera: phát lại video ghi sẵn thay RTSP.

Chưa viết. Topic MQTT: `docs/mqtt-topics.md`.
